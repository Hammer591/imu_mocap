## 启动方式

### 直接运行（不依赖 ROS2）

```bash
# 自检（不连硬件）
python3 ~/imu_mocap/jetson_mocap_v2.py self-test

# 带终端打印（每 20 包）
python3 ~/imu_mocap/jetson_mocap_v2.py --port /dev/ttyACM0 run --print-every 20

# 静默记录到 CSV
python3 ~/imu_mocap/jetson_mocap_v2.py --port /dev/ttyACM0 run --csv data.csv --print-every 0

# 采集 30 秒自动停止
python3 ~/imu_mocap/jetson_mocap_v2.py --port /dev/ttyACM0 run --duration 30 --csv data.csv
```

### ROS2 节点（发布标准 IMU 话题）

```bash
# 一键启动
~/imu_mocap/run_ros2_mocap.sh

# 或手动 source 后运行
source /opt/ros/foxy/setup.bash
source ~/imu_mocap/ros_ws/install/setup.bash
python3 -c "from imu_mocap_node.mocap_node import main; main()"

# 查看发布的话题
ros2 topic list
ros2 topic echo /left_thigh/imu
```

## ROS2 节点架构

```
话题:
  /imu0                sensor_msgs/Imu     D435i 相机 gyro + accel（无姿态）
  /left_thigh/imu      sensor_msgs/Imu     IMU 6 轴 + 四元数姿态
  /left_shank/imu      sensor_msgs/Imu     同上
  /right_thigh/imu     sensor_msgs/Imu     同上
  /right_shank/imu     sensor_msgs/Imu     同上
  /left_foot/imu       sensor_msgs/Imu     同上
  /right_foot/imu      sensor_msgs/Imu     同上
  /left_foot/wrench    geometry_msgs/WrenchStamped  足底 COP + GRF
  /right_foot/wrench   geometry_msgs/WrenchStamped  同上

帧 ID: imu0, left_thigh, left_shank, right_thigh, right_shank, left_foot, right_foot
```
